# Analysis and Design of Algorithms


This repository presents all my homework related to my Analysis and Design of Algorithms course, from my first year PhD student. Improtant to note that the majority of these solutions are pure equations and comparisons related to algorithm analysis. I also include the Jupyter Notebooks for the neede implementations, for example, Hanoi Tower.
It contains the following topics in order of sessions, topics and subtopics:

1. Introduction to algorithms and computational complexity:
* Motivation on the analysis of algorithms
* Classification of problems
* Basic mathematical tools
* Characteristics of algorithms
* Asymptotic notations


2. Design of efficient algorithms:
* Divide and Conquer
* Dynamic Programming
* Greedy algorithms


3. Sorting problems:
* Lower bound of sorting (worst and average cases)
* Worst and average case analysis of several sorting algorithms
* Inversions in Sorting


4. Search and order statistics:
* Binary search and its computational analysis (worst and average case)
* Algorithms for finding the minimum and maximum and the second maximum
* Algorithm for finding the kthmaximum in linear time


5. Matrix multiplication and polynomial evaluation:
* Classic algorithm for matrix multiplication
* Winograd’s algorithm and its complexity analysis
* Strassen'salgorithm and its complexity analysis
* Lower bound for multiplying matrices
* Polynomial evaluation algorithms


7. Graph algorithms:
* Introduction and general graph concepts
* Search in graphs: depth and breath
* Greedy algorithms in graphs
* Minimum Spanning Tree (MST) algorithms
* Shortest paths
* Biconnected componenents
* Maximum flow


9. NP problems:
* P vs. NP
* Features of NP problems
* NP completeness and reducibility
* NP problems (decision vs. optimization)
* Heuristic algorithms for NP problems
* NP hardness
